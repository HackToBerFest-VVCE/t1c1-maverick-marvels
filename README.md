# t1c1-maverick-marvels
Private hackathon repository for Maverick Marvels

AI-powered audit system for VB-G RAM G workers to detect wage and attendance discrepancies.
Uses Gemma 4 to extract data from job cards, passbooks, muster rolls, and worksite records.
Workers verify extracted information before any calculations or audit decisions are made.
Python-based functions securely calculate wages, missing days, delayed payments, and compensation.
Generates multilingual audit reports, grievances, muster-roll requests, and Gram Sabha findings.
Goal: 90%+ printed accuracy, 75%+ handwriting accuracy, 100% arithmetic detection, under 3 minutes.
